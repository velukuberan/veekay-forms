# Veekay Forms

Veekay Forms is a Gutenberg-based form builder for WordPress.

The project is currently under active development.

## Requirements

- WordPress 6.7 or later
- PHP 8.1 or later

## Development

Install the PHP development dependencies:

```bash
composer install
```

Run the PHP quality checks:

```bash
composer check
```

Individual checks can also be run with:

```bash
composer lint
composer analyse
composer test
```

## Project Status

Veekay Forms is in the initial development stage and is not yet ready for production use.
