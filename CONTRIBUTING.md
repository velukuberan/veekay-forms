# Contributing to Veekay Forms

Thank you for your interest in contributing to Veekay Forms.

Veekay Forms is currently under active development. Contribution guidelines will be expanded as the project matures.

## Development

Install the PHP development dependencies:

```bash
composer install
```

Before submitting changes, run the project quality checks:

```bash
composer check
```

## Pull Requests

Keep pull requests focused on a single change.

Before opening a pull request:

- Follow the project's coding standards.
- Add or update tests when applicable.
- Ensure all quality checks pass.
- Perform a self-review of your changes.

Please use the repository's pull request template when opening a pull request.
